# calorie-tracker
Calorie tracker with FastAPI backend and image-based food recognition

Для фронтенда пока будет использоваться Streamlit, чтобы можно было быстро протестировать и продемонстрировать пользователям прототип сервиса. С его помощью пользователи смогут загружать фотографии, которые отправляются на сервер (бэкенд), а полученные результаты, такие как общая пищевая ценность продуктов, будут отображаться на экране пользователя.

На стороне бэкенда используется FastAPI — современный и быстрый веб-фреймворк для создания API. Когда пользователь загружает изображение продукта, FastAPI принимает этот запрос и передаёт фото в LLM (большую языковую модель). Модель анализирует изображение, идентифицирует продукты на нём, а затем рассчитывает их общую пищевую ценность, включая калории, белки, жиры и углеводы. Результаты анализа возвращаются на бэкенд для последующей отправки во фронтенд.


Таким образом, наш сервис будет работать следующим образом:

- Пользователь загружает фото через интерфейс, созданный с помощью Streamlit

- Streamlit отправляет фото на сервер, используя FastAPI сервис

- FastAPI сервис отправляет запрос, содержащий изображение в LLM-модель (ассистенту) для анализа
- Ассистент анализирует фото и возвращает результат анализа обратно в FastAPI сервис
- FastAPI сервис отправляет полученные данные на фронтенд, где пользователь видит информацию о пищевой ценности блюда на экране.

Для решения задачи мы используем ChatGPT-like модель LLaVA, предназначенную для общего понимания изображений и текста, с заявленными возможностями аналогичными мультимодальной версии GPT-4. Запуск модели будет осуществляться с помощью сервиса replicate.com.
